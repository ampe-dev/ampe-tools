# AMPE Server Inventory

Открытый исходный код служебного сценария `ampe_inventory.cmd` для получения списка файлов и каталогов.

## Назначение

Сценарий запускается в выбранной папке Windows и рекурсивно перечисляет ее содержимое, включая относительные каталоги, полные пути, размеры файлов и даты изменения. Итоговый отчет сохраняется в той же папке как `ampe_inventory.txt`.

Сценарий **не передает данные в интернет**, не меняет перечисляемые файлы и не копирует их содержимое. Используется стандартная утилита Windows `robocopy` с параметром `/L` (list only). Создается только файл отчета. Для корректной работы необходимы права чтения выбранной папки и право создания файла отчета.

## Использование

1. С разрешения владельца системы скопируйте `ampe_inventory.cmd` в папку, которую требуется инвентаризировать.
2. При желании изучите содержимое файла в любом текстовом редакторе.
3. Запустите файл двойным щелчком.
4. Дождитесь сообщения `Scan completed` и найдите `ampe_inventory.txt` рядом со сценарием.
5. Проверьте содержимое отчета перед передачей: имена файлов и пути могут содержать конфиденциальную информацию.

Сканируется **только папка расположения сценария и ее подпапки**, а не весь диск. Символические ссылки и точки соединения не обходятся. Если сканирование завершается с ошибками, отчет может быть неполным.

## Параметры

- `/L`: только список, без копирования и удаления данных.
- `/E`: включая вложенные и пустые папки.
- `/XJ /SL`: не переходить внутрь ссылочных каталогов.
- `/FP /BYTES /TS`: полные пути, байтовые размеры, время изменения.
- `/XF`: исключить создаваемый отчет из списка файлов.
- `/UNILOG`: сохранить Unicode-отчет.

## Верификация

Версия: **1.0**. Формат исходного файла: ASCII, переводы строк CRLF.

SHA-256 файла `ampe_inventory.cmd`:

```
2EB26D3F8B137D44DBAD4B8A7F81F85A09E0CC3E62C54239C96D14FC92718B5D
```

Проверка полученного файла в PowerShell:

```powershell
(Get-FileHash -Algorithm SHA256 -LiteralPath ".\ampe_inventory.cmd").Hash
```

Публичная публикация исходника не является цифровой подписью, а совпадение SHA-256 подтверждает идентичность конкретных байтов проверяемого файла указанной версии.

## Ограничения

Сценарий не читает содержимое файлов, не определяет, какие обработки используются в текущей интеграции, и не выполняет аудит безопасности. Запускайте его только в разрешенных каталогах. AMPE не получает отчет автоматически.
