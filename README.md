# AMPE — открытые инженерные инструменты

Публичные вспомогательные инструменты AMPE. Исходный код открыт для проверки перед использованием.

## Инвентаризация файлов (Windows)

**[AMPE Directory Inventory — исходный код и описание](server-inventory/)**

- Файл для запуска: [`ampe_inventory.cmd`](server-inventory/ampe_inventory.cmd).
- Запуск: поместите CMD в разрешённую для обследования папку и дважды щёлкните по нему.
- Результат: `ampe_inventory.txt` рядом со скриптом. В отчёте — названия файлов и каталогов, размеры и даты изменений.
- Скрипт не передаёт данные по сети и не копирует, не меняет и не удаляет исходные файлы.
- **Версия:** 1.3
- **SHA-256 CMD-файла:** `6791E96966712EE61429522465805DB81F7B4EC6965EF0AA6E0B972FF825FE6C`.

Подробное назначение, ограничения и способ проверки опубликованы в [паспорте инструмента](server-inventory/README.md).

Инвентаризацию следует выполнять только с разрешения владельца системы. Перед передачей отчёта проверьте содержащиеся в нём пути и имена файлов: они могут быть конфиденциальными.
